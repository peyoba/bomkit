# 10 · A浅色方案实施与本地验证

## 已确认范围

用户原话：“就用A方案吧，不要融合了”。只采用已展示的A浅色专业方向，不混入B、不增加主题切换。完整选择记录见direction-approved.md；原型快照与图片位于docs/design，色彩与结构约定见design.md。

本轮在本地分支codex/ui-a-light实现，不推送Vercel生产分支。网站是否更新必须以之后明确发布操作为准。

## 已实现

- A横向导航、白底/冷灰预览区/钴蓝主操作、左侧文件表单与右侧样式示意。
- 首页继续保留开始转换；导航保留Excel转换和网页校对（可选），不删除原路径。
- 文件选择使用真实本机读表能力：空态不填示例、显示读取中/错误/所选文件，保留工作表选择；可清除物料表回到“不提供库”的原有能力。
- PCBA名称/型号、PCB空板名称/型号、输出文件名、可选附表完整保留。按钮直接生成Excel，不恢复网页强制确认。
- 样式示意始终写明“主表局部·合成示例，非实时预览”；并非用户已导入数据、实时结果或新增模板编辑器。
- 表单读取/转换时禁用导航和重复下载，错误就地显示，成功信息仍有真实行数/数量及候选需Excel删选的说明。
- 独立token和样式文件；旧全局index.css未删改，可选网页校对业务代码未修改。

## 验证注意事项

默认批量Excel E2E在下载前等250ms，避免Chromium快速连续下载节流：独立测试中约50ms的连续第11次被拦截，而250ms节奏13次全部成功。该间隔只在测试脚本，不影响用户生成速度。脚本失败时保存界面和表单诊断，不将浏览器节流误判为DNP/核心转换错误。

## 本地复现

在web目录，先npm run build并保持127.0.0.1:4173的preview运行，然后执行：

    BOMKIT_PRIVATE_TESTS=1 npm test
    npm run lint
    npm run test:e2e:ui
    BOMKIT_PRIVATE_TESTS=1 npm run test:e2e

没有私有样例时不设置BOMKIT_PRIVATE_TESTS。界面额外脚本只使用合成输入，结果与截图保存在Git忽略的core/tests/fixtures/private/ui-a-validation/。私有文件不提交、不推送。
