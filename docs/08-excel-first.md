# 08 · Excel优先与原公司能力兼容

## 用户确认的方向（2026-09-09）

多候选、分组合并和校对位置都沿用原公司工具；在Excel展开/删选/修改，减少网页确认。网页校对仅作可选增强，原工具能力不能因重构被删除。

## 默认路径

选择BOM、可选物料表、填写可选PCBA/PCB信息 → 一键生成Excel → Excel里处理候选/未匹配/数量。没有校对人必填、逐行确认或“未确认不能下载”的网页门禁。

- 输入支持原嘉立创必需列Name/Designator/Quantity/Footprint，Device及厂商/说明/类别/精度可选；已验证的Altium/Cadence仍可转换到公司主表。
- 支持金蝶完整表和旧简易规格/物料编码/金蝶系统型号；保留前导零、禁用过滤，旧简易字典重复规格按旧方式取最后一条。
- 按值/封装/DNP合并，位号自然排序、数量求和，其余取首个非空，按旧类别顺序/DNP沉底。
- 多候选全部展开；候选组按旧色带交替。精确/型号绿、低置信度料号琥珀、参数蓝、未匹配红、非物料灰；缺编码/规格黄、DNP说明暗红。保留厂商与原型号/Description辅助列。
- 保留PCBA名称/型号、PCB空板名称/型号与空板行。网页浏览器下载；CLI保留原-o行为、防重名默认命名和三次文件占用重试。
- 附表可选，不改变主表：完整原始输入及Excel校对提示；组内型号/厂商/精度冲突仅提示，不擅自更改旧合并逻辑。参数冲突也在Excel提示，不把网页确认重新加回来。
- 5000个相同项仍合成1组；仅在位号字符串超过Excel单元格上限时移除逗号后的空格，确保R1到R5000都保留。再长则明确报错，不静默截断。

## 与保留功能的关系

v1冻结契约保持原文；新Worker excel命令独立进入excel_api。原可选网页v2及其自定义中文模板/人工处理能力保留，不是默认导出的前置步骤。

默认Excel暂用公司原版模板；远端独立模板标注/Profile线没有自动合并。可选v2也修复源型号/值/封装列互相矛盾的自动放行，以及中文欧单位的误提示，二者不改变默认Excel下载方式。
