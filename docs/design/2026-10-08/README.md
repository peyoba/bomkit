# bomkit 网站 UI 原型 · 2026-10-08

## 项目检查与设计依据
- 当前代码为 React / TypeScript / Vite / Ant Design / Zustand；Python 核心通过 Pyodide Worker 在浏览器本地执行。
- 当前 README 与实际 Home、ExcelWorkspace、ReviewWorkspace 优先于早期通用化计划。默认 Excel 转换与可选网页校对不能混为强制连续流程。
- 沿用根目录 direction-approved.md 中已确认的 A 浅色专业方案，不融合其它方向。已有文字标识、字体与根 tokens.css 为视觉依据。
- 未检查线上部署状态，不把历史部署记录当作当前线上验收。

## 本轮产物
- index.html：首页，以工具价值、Excel 样式示意、三步流程组织内容。
- convert.html：左表单右输出示意；保留工作表、可选物料表、PCBA/PCB 信息、文件名、附表选项。
- review.html：独立可选校对页面；条目筛选、搜索、查看原始数据与候选详情。
- prototype.css / prototype.js：独立样式与演示交互，不接入生产业务。
- *-desktop.png / *-mobile.png：3 个页面各自的桌面和 375px 移动端截图。

## 浏览与交互
直接打开 index.html（同目录 CSS/JS 必须一并保留），或在此目录运行本地静态服务器。
页面顶部导航可互相切换；转换页载入合成示例后展示模拟转换反馈；校对页支持筛选、搜索、行详情切换。
所有数据均为合成示例；不读取/上传真实文件，不生成 Excel，不执行实际确认或审核。完整确认表单及输出门禁仍以生产实现为准。
